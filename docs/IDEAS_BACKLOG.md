# Ideas backlog

These are intentionally outside the first vertical slice:

- Apple Watch remaining-stop complication and arrival handoff.
- AirPods spoken prepare/arrival cues using supported notification paths.
- Android foreground-service and notification companion.
- Place-to-place journey planning and transfer support.
- Offline saved stop sequences and graceful last-known schedule mode.
- Tourist language packs: Japanese, Simplified/Traditional Chinese, Indonesian, Vietnamese, and Thai.
- Caregiver-shared destination templates without live passenger surveillance.
- Post-ride reliability feedback and privacy-preserving matcher evaluation.
- Operator disruption messages and accessibility-specific stop guidance.

Each idea needs evidence that it strengthens the core “board, close, get off correctly” promise without turning TAPSO into a general map app.

# Design principles

1. Glance, then put the phone away.
2. The destination and remaining-stop count outrank maps and decoration.
3. Confidence and freshness must be visible when they affect action.
4. Korean-first warmth with an independent mint, ink, and mist visual language.
5. Use Dynamic Type, VoiceOver labels, sufficient contrast, and words/icons in addition to color.
6. Escalate calmly: normal progress, prepare at two, strong next-stop signal at one, unmistakable arrival at zero.
7. Keep the main app small; Dynamic Island is a first-class product surface.
8. Treat two, one, and zero stops as different decisions, not smaller versions of the same counter.
9. Track the vehicle, not the passenger: location permission is not a prerequisite for the ride surface.
10. Be cute through compact geometry and tone—a tiny sparkle, friendly squircle, rounded numerals—not through decoration that competes with the stop signal.
11. Never let color imply more certainty than the matching engine has. Show Live Activity connectivity and vehicle-match confidence as separate trust signals.
12. Express Jeju through an original, state-reactive basalt buddy, tangerine destination dots, sea-foam waves, and warm copy—not borrowed mascots or reference-app artwork.

Public reference research included 지하섬's promise of an always-visible remaining-stop signal, a stronger one-stop warning, low setup burden, and a small characterful identity that remains legible over other apps. TAPSO translates those product lessons into its own vehicle-confidence model, mint/amber/coral escalation, a blue fail-closed checking state, state pills, moving-bus progress rail, typography, copy, and layout. Its Dynamic Island uses an original basalt “돌이” companion whose expression changes with journey state, a tangerine destination marker, and subtle sea-foam wave/sunrise motifs. The main ride card mirrors the same phase color so app and Island feel continuous, while a compact trust strip separates Island connectivity from vehicle-match confidence. No reference brand assets, screenshots, icons, illustrations, or distinctive screen composition are copied.

# Roadmap

1. Run the credentialed Jeju data spike and publish an evidence matrix.
2. Capture multi-poll sanitized fixtures for simple, frequent, opposite-direction, and variant routes.
3. Calibrate matcher thresholds and add replay/cross-language conformance tests.
4. Add route/boarding/destination setup and accessible ambiguity confirmation.
5. Implement cached shared fleet polling and durable ride sessions.
6. Register and rotate ActivityKit update tokens through the API.
7. Implement APNs update/end delivery, budgets, idempotency, and observability.
8. Test 30+ real boardings, including stale and dropout cases.
9. Complete physical-device Dynamic Island, Lock Screen, VoiceOver, battery, and localization QA.
10. Threat-model, privacy-review, brand-clear, beta distribute, and add rollback/incident playbooks.

Later ideas—Apple Watch, AirPods announcements, Android, place routing, journey history—remain behind evidence that the core ride companion is trustworthy.
